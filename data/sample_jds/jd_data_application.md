# JD - Data Application Engineer

## Job Description

1. Responsible for ETL, server-side processing, and product applications based on data warehouse.
2. Build and optimize real-time, offline, data lake, and data service platform capabilities.
3. Develop data modeling and mining by theme and business domain.
4. Explore AI applications in data analysis and modeling. Use AI tools to assist SQL generation, data exploration, and feature engineering.

## Requirements

1. Computer science or related background.
2. Skilled SQL and Python for data analysis and modeling.
3. Understand common machine learning algorithms and data visualization.
4. Strong communication, responsibility, and fast response to business/product iteration.
5. Skilled use of AI tools for data processing and modeling.
