# Sample JD: AI Agent Engineer

## Responsibilities

- Build AI Agent applications for real business scenarios.
- Use tools/function calling and workflow automation.
- Evaluate AI tools and document reusable solutions.
- Work with product, engineering, and operations teams.
- Improve reliability and usability through iteration.

## Requirements

- Python or Java development experience.
- Basic understanding of LLM, Agent, API/tool calling.
- Experience with AI Coding tools such as Claude Code, Codex, or Cursor.
- Ability to record conclusions and unresolved issues clearly.

## Bonus

- RAG, MCP, Docker, FastAPI, Redis, vector database.
- Observability, permission control, cost analysis.

## Expected System Behavior

The system should mark RAG, MCP, Docker, FastAPI, Redis, and vector database as not writable unless the fact bank contains project evidence.
