# Tencent - AI Application Engineer

## Job Description

1. Develop and deliver AI application products, turning large model capabilities into user-facing product features. Participate in requirement analysis, solution design, implementation, and continuous iteration.
2. Build business applications based on large models, including intelligent dialogue, content generation, recommendation, and knowledge Q&A.
3. Focus on user experience and product quality. Establish effect evaluation and feedback optimization loops to improve application performance.

## Requirements

1. Good software engineering ability and mainstream development stack.
2. Skilled use of AI programming tools to improve development efficiency and code quality.
3. Understand basic LLM principles and mainstream model API integration.
4. Understand RAG principles, including document parsing, chunking, vectorization, retrieval, and ranking.
5. Product thinking from the user's perspective.
6. Communication, collaboration, learning ability, and enthusiasm for AI applications.

## Bonus

1. AI application project experience.
2. RAG system experience and vector database tuning.
3. Product design understanding and independent product or deployed work.
4. Competitions, open-source projects, or technical content output.
